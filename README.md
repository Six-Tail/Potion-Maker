# 🧪 물약 공방 (Potion Maker)

> PC를 사용하면 연금술사가 물약을 만들어 주는 Windows 데스크톱 위젯 게임

**물약 공방**은 바탕화면 한켠에 띄워두고 즐기는 방치형 위젯 게임입니다.
거대한 항아리에 재료를 넣고 제작 시간을 정한 뒤 제작을 시작하면, **당신이 PC를 사용하는 동안에만**
연금술사가 물약을 젓습니다. 자리를 비우면 캐릭터도 꾸벅꾸벅 졸며 제작을 멈추죠.
정해둔 활동 시간이 다 차면 **재료 조합과 제작 시간대에 따라 서로 다른 물약**이 완성됩니다.

## ✨ 주요 특징

- **PC 사용 감지형 진행** — 등록한 프로그램(예: 크롬, 작업용 앱)이 화면 맨 앞(활성 창)일 때만 제작이 진행됩니다. "일하는(혹은 노는) 동안 물약이 만들어지는" 방치형 재미.
- **살아있는 연금술사** — 사용 중엔 국자를 저으며 물약을 만들고, 대기 중엔 `Zzz` 하며 졸음.
- **조합 × 시간 레시피** — 같은 재료라도 제작 시간대가 다르면 다른 물약이 나옵니다.
- **항상 위 위젯 창** — 제목표시줄이 있는 작은 창이 다른 창 위에 떠 있어 곁눈질하며 즐기기 좋습니다.
- **보관함 · 레시피 도감** — 만든 물약을 모으고, 발견한 레시피를 도감에 기록합니다.
- **자동 저장** — 진행 중인 제작·보관함·설정이 자동 저장되어 창을 닫아도 이어집니다.

---

## 🎮 게임 방법

1. **재료 담기** — 아래 재료 버튼을 눌러 항아리에 최대 3개까지 넣습니다.
2. **시간 설정** — 슬라이더로 제작 시간(분)을 정합니다.
3. **대상 앱 등록** (최초 1회) — ⚙설정에서, 원하는 프로그램(예: 크롬)을 클릭해 활성화한 뒤 **"현재 외부 창 등록"**을 누릅니다.
4. **제작 시작** — 등록한 프로그램을 사용하는 동안 제작이 진행됩니다. 활동 누적 시간이 목표에 도달하면 물약 완성!

> 💡 처음 테스트해 볼 땐 ⚙설정의 **"강제 진행"** 체크 + **제작 속도 60배**로 두면 앱 등록 없이 바로 결과를 볼 수 있습니다.

### 레시피 예시

| 재료 | 시간 | 결과 물약 |
|------|------|-----------|
| 약초 + 이슬 | 1~15분 | 활력의 물약 |
| 불꽃 + 수정 | 1~15분 | 화염의 물약 |
| 수정 + 이슬 | 15~60분 | 마나 물약 |
| 약초 + 버섯 + 수정 | 15~90분 | 만병통치약 |
| 뼈 + 불꽃 | 30~180분 | 부활의 물약 |

조합이 맞지 않으면 *정체불명의 물약*이 나옵니다. 나머지 레시피는 직접 발견해 보세요! (재료 8종 · 레시피 10종)

## 🚀 실행 방법

### 요구 사항
- **Windows** (PC 사용 감지가 Windows 전용 API 기반)
- **Godot Engine 4.7.2** ([공식 사이트](https://godotengine.org/download))

### 에디터로 열기 / 실행
```bash
# 저장소 클론
git clone https://github.com/Six-Tail/Potion-Maker.git

# Godot 4.7.2 실행 파일로 프로젝트 열기
Godot_v4.7.2-stable_win64.exe --editor --path Potion-Maker

# 바로 실행
Godot_v4.7.2-stable_win64.exe --path Potion-Maker
```

> Godot 엔진 실행 파일은 용량 문제로 저장소에 포함되어 있지 않습니다. 공식 사이트에서 4.7.2 버전을 내려받아 사용하세요.

## 🛠 PC 사용 감지 원리

GDScript만으로는 다른 창의 정보를 알 수 없어서, 백그라운드에서 **PowerShell 헬퍼**를 콘솔 창 없이(`wscript`) 실행합니다.
이 헬퍼가 Windows API(`GetForegroundWindow`)로 현재 **최상위(포그라운드) 창**의 정보를 파일에 계속 기록하고,
게임이 이를 주기적으로 읽어 "등록된 프로그램이 최상위인가?"로 사용 여부를 판정합니다.
헬퍼는 게임 종료 시 스스로 정리되어 백그라운드에 남지 않습니다.

## 📁 프로젝트 구조

```
Potion-Maker/
├─ project.godot              # 프로젝트 설정 (창 크기, 항상 위, 오토로드)
├─ main.tscn                  # 메인 씬
├─ icon.svg                   # 앱 아이콘
└─ scripts/
   ├─ main.gd                 # 전체 UI 구성 및 게임 흐름
   ├─ game_state.gd           # 상태(항아리·제작·보관함·도감·설정) + 저장 (오토로드)
   ├─ recipes.gd              # 재료/레시피 DB + 판정 로직 (오토로드)
   ├─ foreground_watcher.gd   # 포그라운드 창 감지 (오토로드)
   └─ cauldron_view.gd        # 항아리·액체·거품·캐릭터 코드 드로잉
```

## 🧰 기술 스택

- **엔진**: Godot Engine 4.7.2 (GDScript, `gl_compatibility` 렌더러)
- **PC 사용 감지**: Windows PowerShell + Win32 API (`user32.dll`)
- **아트**: 코드 기반 드로잉 (에셋 없이 동작하는 플레이스홀더)
